HDL-X 0.1.0 — Windows x64 GUI
================================

运行方法
--------
双击 HDL-X.exe。请保留 HDL-X.exe 和 _internal 文件夹的相对位置，
不要只复制 EXE；程序运行不需要另行安装 Python 或 GHDL。

基本操作
--------
1. 选择一个 .vhd / .vhdl 输入文件。
2. 选择要写入的 .v 输出文件。
3. 保持“严格”模式，按需选择名称风格和目标验证。
4. 点击“开始转换”，在右侧预览生成的 Verilog-2001。

当前范围
--------
这是单文件 VHDL-2008 可综合 RTL 子集到 Verilog-2001 的 MVP。
遇到无法安全转换的语义时，程序会明确报错，不会静默猜测。

故障信息
--------
若程序在界面出现前失败，同目录会生成 HDL-X-error.log。
本构建未做代码签名，Windows 可能显示未知发布者提示。
